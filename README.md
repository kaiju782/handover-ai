# 🗂️ 경영사무 AI 인수인계 도우미 (프로토타입 v2)

자료를 **통째로 올리면** 4단계로 인수인계서를 완성하는 웹앱입니다.

| 단계 | 하는 일 |
|---|---|
| 1. 자료 업로드 | 여러 파일 / ZIP 업로드 → 자동 분류(양식·완료 문서·규정·메모) + 텍스트 추출 |
| 2. AI 1차 분석 | **0. 빈 서식 vs 완료 문서 1:1 대조** + 1차 초안 + **자료에 맞춰 달라지는 질문(보통 5~15개, 필수/권장 배지)** |
| 3. 인계자 Q&A + 검수 | 답변 입력 → **🔍 AI 답변 검수**(충분함 ✅ / 보완 필요 ⚠️ + 재질문) → 고쳐서 재검수 → 기타 인계 메모 |
| 4. 최종 완성 | ① 업무 절차 ② 숨은 예외 FAQ ③ 월간/연간 마감표 ④ 서식·참고파일 맵 + ⑤ 기타 인계 메모 → Markdown / Word 내보내기 |

**API 키가 없어도 4단계 전체를 그대로 체험할 수 있습니다(데모 모드).**
데모 모드도 하드코딩 문구가 아니라, 업로드한 파일에서 실제로 뽑은 문장·수치(예산 총액, 팀원 이름, 기간, 일정 주차, 서식 빈칸, 서로 다른 금액 등)를 근거로 초안·질문·검수를 만듭니다.

---

## 0. v2에서 달라진 점

1. **빈 서식 ↔ 완료 문서 1:1 대조** — 1차 초안 맨 앞에 `## 0. 빈 서식 vs 완료 문서 대조 요약`이 붙습니다.
   - 양식 항목별로 *양식에 적힌 값 / 완료 문서에서 채운 내용 / 상태*(확인됨·값 다름·완료 문서에 없음·양식 빈칸)를 표로 보여 줍니다.
   - 서식엔 없지만 완료 문서에서 추가로 챙긴 내용, 양식과 완료 문서의 숫자·기한이 어긋나는 지점을 따로 정리합니다.
   - 완료 문서 없이 양식만 올라온 경우에는 **양식이 비워 둔 칸**만 짚어 줍니다.
2. **질문 개수 유동화 + 중요도** — "정확히 5개" 고정을 없앴습니다. 자료의 빈칸·불일치·모호함 수에 따라 5~15개로 달라지고, 각 질문에 `필수`/`권장` 배지와 분류(승인·결재, 예외·규정, 일정·마감, 서식·작성법, 연락·창구, 예산·증빙)가 붙습니다.
3. **인계자 답변 AI 검수** — Step 3에서 답변을 쓴 뒤 `🔍 AI로 답변 검수받기`를 누르면 바로 최종본으로 가지 않고 검수를 거칩니다.
   - 너무 짧거나 모호한 답변("알아서", "문의", "적당히", "팀장님", "그때그때" 등)
   - 자료의 숫자·기한과 어긋나는 답변
   - 누가/언제/어떻게 기준이 빠져 후임자가 실행할 수 없는 답변
   - 결과는 답변마다 `충분함 ✅` / `보완 필요 ⚠️` 배지와 구체적인 재질문으로 표시되고, 고친 뒤 **다시 검수**하거나 **최종 인수인계서 생성**으로 넘어갑니다. (검수 없이 바로 생성하는 작은 보조 버튼도 있습니다)
4. **기타 인계 메모** — 질문에 담기지 않은 판단 기준·비상 연락처를 인계자가 직접 적는 칸이 생겼고, 최종본 `## ⑤ 기타 인계 메모`로 들어갑니다. 검수 이력도 최종본 맨 뒤 표로 남습니다.

## 1. 설치

Python 3.10 이상이 필요합니다.

```bash
cd handover-ai
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## 2. 실행

```bash
streamlit run app.py
```

브라우저가 자동으로 열립니다(`http://localhost:8501`). 열리지 않으면 주소를 직접 입력하세요.

## 3. 사용

1. 왼쪽 사이드바에서 **실행 모드**를 고릅니다. (처음엔 `데모 모드 (API 키 불필요)` 그대로)
2. **Step 1** — 인수인계할 자료를 한꺼번에 올립니다. hwp / hwpx / pdf / docx / xlsx / xls / csv / txt / md / **zip** 지원.
   - 올린 파일은 자동으로 *양식 / 완료 문서 / 규정·메모* 로 분류됩니다.
   - `📄 추출 텍스트 미리보기`를 펼치면 실제로 뽑힌 글자를 확인할 수 있습니다.
3. **Step 2** — `분석 시작`을 누르면 ① 1차 초안(**0장 서식 대조 포함**)과 ② 질문 목록 탭이 생깁니다.
4. **Step 3** — 질문에 인계자가 답합니다. **🔍 AI로 답변 검수받기** → `보완 필요` 코멘트를 보고 고친 뒤 **다시 검수** → `최종 인수인계서 생성`으로 넘어갑니다. 아래 `✍️ 기타 추가로 남길 인계 메모`도 함께 적을 수 있습니다.
5. **Step 4** — `최종 인수인계서 만들기` → 미리보기 확인 → **Markdown(.md) / Word(.docx)** 내려받기.

## 4. 실제 API 연결 (K-water GPT / OpenAI 호환)

사이드바에서 **실제 API 연동**을 고르면 세 칸이 나타납니다.

| 칸 | 넣을 값 |
|---|---|
| `base_url` | OpenAI 규격 엔드포인트. OpenAI는 `https://api.openai.com/v1`. **K-water GPT는 담당자에게 받은 게이트웨이 주소**(보통 `https://…/v1`) |
| `api_key` | 발급받은 키. 화면에는 가려져 표시되고 파일로 저장되지 않습니다. |
| `model` | 사용할 모델명. K-water GPT 안내서에 적힌 이름 그대로. OpenAI 예: `gpt-4o-mini` |

- **키 교체는 이 세 칸만 바꾸면 됩니다.** 코드 수정이 필요 없습니다.
- `연결 확인 (1회 호출)` 버튼으로 먼저 연결을 점검하세요. (실제 1회 호출 — 제공처 정책에 따라 소액 과금될 수 있습니다)
- 호출 규격은 `POST {base_url}/chat/completions` (OpenAI Chat Completions)입니다. 사내 게이트웨이가 같은 규격이면 그대로 동작합니다.
- 인증 헤더는 `Authorization: Bearer <api_key>`입니다. 사내 규격이 다르면 `llm.py`의 `call_llm()` 한 곳만 고치면 됩니다.
- 실제 API 모드에서 쓰는 프롬프트는 세 개입니다: `prompt_analysis`(서식 대조 + 유동 질문), `prompt_review_answers`(답변 검수), `prompt_final`(최종본).

> ⚠ 실제 API 모드에서는 **추출된 문서 텍스트가 해당 제공처로 전송**됩니다.
> 사내 자료라면 ① 사이드바의 `민감정보 자동 마스킹`을 켜고, ② 반출 정책을 먼저 확인하세요.

## 5. HWP를 어떻게 읽나요?

`.hwp`(한글 5.0 바이너리)는 **순수 파이썬 파서**로 읽습니다. 한글 프로그램, `rhwp`, `pyhwp` 설치가 필요 없습니다.

- OLE 복합문서(`olefile`) → `BodyText/Section*` 스트림 → zlib 해제 → `HWPTAG_PARA_TEXT` 레코드에서 UTF-16 문자 추출
- 표 안의 글자도 같은 레코드로 들어오므로 **표 셀 텍스트까지** 뽑힙니다.
- 본문이 비어 있으면 `PrvText`(미리보기 텍스트)로 대체합니다.
- 암호가 걸린 문서는 열지 않고 "암호가 걸린 문서"라고 알려 줍니다(임의 변환 없음).
- `.hwpx`는 ZIP+XML(`Contents/section*.xml`)로 읽습니다.

검증 결과는 `python verify.py` 로 언제든 다시 확인할 수 있습니다.

## 6. 민감정보 마스킹

사이드바 토글이 켜져 있으면 **화면 표시·LLM 전송 전에** 아래 항목을 가립니다.

| 항목 | 예 |
|---|---|
| 주민등록번호 | `900101-1234567` → `900101-1******` |
| 휴대폰 | `010-1234-5678` → `010-****-5678` |
| 계좌번호 | `123-456-789012` → `계좌번호 ********9012` |
| 카드번호 | `1234-5678-1234-5678` → `카드번호 ************5678` |
| 사업자번호 | `123-45-67890` → `123-**-6****` |

끄면 원문 그대로 처리합니다(민감정보가 LLM으로 갈 수 있으니 주의).

## 8. 파일 구성

```
handover-ai/
├─ app.py            # Streamlit 화면 (4단계 워크플로우)
├─ parsers.py        # 파일 추출(HWP/HWPX/PDF/DOCX/XLSX/XLS/CSV/TXT/ZIP) · 자동 분류 · 마스킹
├─ llm.py            # 실제 API 어댑터 + 프롬프트(분석·검수·최종) + 데모 생성기
├─ exporters.py      # Markdown / Word(.docx) 변환
├─ verify.py         # 파싱·대조·유동질문·검수·최종본 자체 점검 스크립트
├─ requirements.txt
└─ README.md
```

## 9. 문제가 생기면

| 증상 | 확인 |
|---|---|
| `streamlit: command not found` | `pip install -r requirements.txt` 후, 가상환경이 켜져 있는지 확인 |
| HWP 글자가 0자 | 암호 설정 문서인지, 한글 3.0 이하 구형인지 확인 (오류 메시지가 표시됩니다) |
| PDF 글자가 거의 없음 | 스캔 이미지 PDF는 텍스트가 없습니다. 한글/워드 원본이나 OCR본을 올려 주세요 |
| 실제 API 401/404 | `base_url`(끝의 `/v1` 포함)과 `model` 이름을 확인. `연결 확인` 버튼으로 먼저 점검 |
| 서식 대조에서 '값 다름'이 뜸 | 두 문서의 금액·기간이 실제로 다를 때 나옵니다. 어느 쪽이 확정인지 Step 3 답변으로 남기세요 |
| 표가 Word에서 깨짐 | Markdown 표 형식만 Word 표로 변환합니다. 복잡한 중첩 표는 미리보기에서 확인 후 수정 |
